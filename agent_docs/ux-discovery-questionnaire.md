# Yumami UX Discovery Questionnaire

Use this file to answer the UX/UI discovery questions before the redesign pass.

## Design Direction
Target feeling:
- calm
- organized
- grounded in the real difficulties of a shared household

Later-roadmap idea:
- customizable dashboard with widgets

## Questions
1. When you open Yumami, what are the top 3 things you want to understand within 5 seconds?

2. What are the top 3 actions you want to do most often?

3. What should live on the home dashboard no matter what?

4. Which modules should definitely have their own dedicated pages instead of fully living on the home screen?
Suggested candidates:
- Tasks
- Calendar
- Finance
- Files

5. On the home dashboard, do you want:
- a fixed structured layout
- a mostly fixed layout with a little personalization
- a future customizable widget dashboard, but not yet in v1

6. What should feel emotionally true about the app?
Examples:
- calm
- warm
- intimate
- capable
- clean
- reassuring
- private
- not corporate

7. What should the app avoid feeling like?
Examples:
- enterprise software
- spreadsheet tool
- cluttered admin portal
- generic productivity app
- family social network

8. In the shared-household context, what are the most common real-life moments the app should support?
Examples:
- what do we need to do this week?
- what bill or admin thing is coming up?
- who is handling what?
- where is that document again?
- what are we spending money on this month?

9. Do you want the home screen to be more:
- overview-first
- action-first
- balanced between overview and action

10. On mobile, what navigation feels right to you?
Examples:
- bottom tab bar
- home plus section cards
- home with a menu/drawer
- not sure, want recommendation

11. Do you want the calendar and tasks to feel tightly blended, or clearly separate?
Examples:
- tasks and events should feel like one planning system
- tasks and calendar should stay separate but connected

12. Do you want finance on the home dashboard to be:
- just alerts and summary
- a medium-sized summary section
- one of the main primary sections

13. Same for files:
- just quick access links
- a small dashboard section
- a primary module with strong visibility

14. What kinds of customization should eventually exist?
Examples:
- reorder dashboard widgets
- hide sections
- pin favorite files
- choose default home focus
- choose compact vs detailed home

15. What apps should Yumami feel closest to in tone?
Current references already discussed:
- Apple
- Things
- Notion Calendar
- Cozi / FamilyWall for shared-household practicality
